# Abir Mondal — Portfolio

A premium, dark-themed, responsive portfolio built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run typecheck
npm run build
npm start
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the framework preset as Next.js and the root directory as the project root.
4. Deploy. No environment variables are required.

## Personalization

Project details, social URLs, skills and timeline content are defined near the top of `app/page.tsx`. The public contact email is configured in the `profile` object. Replace `public/resume.pdf` when updating your resume.

## Notes

- No backend, database or API keys are required.
- Project preview panels are CSS-built interface illustrations, not screenshots from the live applications.
- The current resume is included at `public/resume.pdf` and linked from the hero section.
- Review internship dates/details and current LeetCode activity before publishing any additional claims.
